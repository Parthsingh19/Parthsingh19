## 🚀 How to Run Locally

1. **Extract/Clone the repository:**
   Ensure all files (`index.html`, `style.css`, `script.js`, and `Photo.jpg`) are located in the same directory.

2. **Open in Browser:**
   Simply double-click `index.html` or open it using any modern web browser (Google Chrome, Firefox, Safari, or Microsoft Edge).

3. **Deploy to GitHub Pages:**
   - Push the files to a repository named `Parthsingh19.github.io` or `portfolio`.
   - Go to **Settings** > **Pages**.
   - Set the source branch to `main` (or `master`) and folder to `/ (root)`.
   - Save and your site will be live!
